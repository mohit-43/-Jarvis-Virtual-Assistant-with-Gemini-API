# 🤖 Jarvis-Virtual-Assistant-with-Gemini-API
DESCRIPTION: This project develops a personalized, conversational virtual assistant using Python, leveraging Google's Gemini API for sophisticated natural language processing and task execution. It demonstrates proficiency in API integration and custom assistant design.

PROBLEM: Lack of conversational flexibility. Goal: Build a custom, extensible assistant using modern LLM capabilities.

KEY FEATURE:Conversational ai model,gemini 2.5 for the content generation ,secure api handeling by using the os module to prevent api key to be used in hard coding and secrely loading it from environment variable Natural Language Understanding.

METHODOLOGY: wake word> User Input > Python(speechrecognisation) > Gemini API > gtts(for responce) > pygame(convert the responce into audio file and play it ). Tech: Python, google-genai, pyttsx3,gTTs,pygame,webbrowser.

KEY RESULTS: Demonstrated API Integration, proficiency in Prompt Engineering, and handling of real-time custom functions.

FUTURE PLAN : Integrate a persistent SQL database for memory, develop a GUI. Making it more advance and use the complete potential of the gemini into the jarvis.
